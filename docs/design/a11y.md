# Accessibility — Casa dos Frios MVP

Accessibility is a design constraint. Applies to Loja and SaaS.

## Contrast

- Body and status text ≥ **4.5:1** on surfaces.
- Large title text ≥ **3:1**.
- Theme save gate: text on background and text-on-primary on primary (see `tokens.md`).
- Status never relies on color alone — always visible label text.

## Keyboard

- Tab order: chrome → main → primary actions.
- All shadcn Dialog / Sheet / AlertDialog trap focus and restore on close.
- Skip link “Ir para o conteúdo” on Loja and SaaS (visually hidden until focus).
- Illegal / disabled actions are omitted or `disabled` with explanation — not focus traps.

## Focus

- Visible 2px ring using `--ring` ← brand accent (`#1F5C6B` seed) + 2px offset.
- Never `outline: none` without the ring replacement.
- Inbox thread list: arrow keys optional; Enter opens thread (if implemented, document in frontend; mouse/touch sufficient for MVP if roving tabindex skipped — prefer listbox pattern).

## Semantics

- One `h1` per page (Loja hero brand/title or SaaS page title).
- Status changes and notify lines use `aria-live="polite"`.
- Errors linked via `aria-describedby` / `aria-invalid` on fields.
- Decorative gradient tiles `aria-hidden="true"`.

## Touch

- Default controls ≥ 36px; mobile fields ≥ 44px; primary mobile CTAs ≥ 48px.
- WhatsApp CTA and checkout primary remain thumb-reachable on Loja mobile.

## Tax IDs (LGPD)

- Mask in every non-editing view.
- Do not put full CNPJ in `title`, `aria-label`, or `data-*`.
- Screen reader: announce masked form or “CNPJ terminando em {last4}” when needed.

## Cadastro / entitlement-style gates

MVP has **no subscription entitlement**. Gates are **cadastro**:

- Announce gate banners with `role="status"` or `aria-live="polite"`.
- Primary buy/accept controls removed (not merely grayed without reason).

## Motion

- Honor `prefers-reduced-motion: reduce` — zero transform/opacity animation durations.

## Checklist before handoff

| Criterion | Target |
|---|---|
| Contrast body/status | ≥ 4.5:1 |
| Focus visible | yes |
| Keyboard operable paths | login, inbox, approve cadastro, send orçamento, loja checkout |
| Status without color alone | yes |
| Hit targets mobile | ≥ 44–48px primary |
